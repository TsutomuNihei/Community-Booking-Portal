# CoastLink Facility Booking Prototype

A basic browser-based prototype for booking CoastLink Council facilities and equipment. It also provides staff tools for managing bookings and scheduling maintenance.

The prototype is meant to simulate a closed end-to-end scenario of booking a facility/equipment, viewing/cancelling bookins. Admin/Staff being able to control bookings and scheduling maintenance.

To run, download/clone the repo and run the index.html file
